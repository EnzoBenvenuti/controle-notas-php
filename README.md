# Controle de Notas em PHP

Este projeto demonstra o uso de estruturas de repetição e funções
em PHP utilizando um exemplo simples de controle de notas de alunos.

## Conceitos utilizados

- Funções
- foreach
- for
- Arrays
- if/else
- count()

## Funcionamento

O programa apresenta as notas dos alunos, calcula suas médias
e informa se cada aluno foi aprovado ou reprovado.
